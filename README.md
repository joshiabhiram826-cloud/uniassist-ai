Project Overview

UniAssist AI is an AI-powered College Knowledge Assistant designed to help students find relevant information from college documents through natural-language questions.

The project aims to use Retrieval-Augmented Generation (RAG) to retrieve relevant information and generate answers grounded in college documents.

Key Objectives

- Make college information easier to find.
- Support natural-language questions.
- Retrieve relevant information from college documents.
- Provide source references to help users verify answers.
- Reduce unsupported answers when information is unavailable.
